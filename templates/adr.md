ADR is not edited; a later ADR supersedes it. A dated amendment is appended at the end and named in
the Status line. Where this ADR and another document disagree, say which one wins.

## Context

What forced a decision. Include the measurement if there is one, and label any number that is an
estimate rather than a measurement.

## What review changed

New facts found in review, and which decision each one moved. Delete if nothing changed.

## Options considered

1. **Option A.** What it is, what it costs, why it was or was not taken.
2. **Option B.**
3. **The cheaper option, priced.** What the smallest thing that could work would cost and lose.

An ADR with no rejected option is a note, not a decision.

## Decision

For each decision: what was decided, why, the consequence, and how it interacts with the other
decisions here. Cite the seams it touches by file and line. Code that applies a decision cites its ID.

## Consequences

What gets easier, what gets harder, and what must now be checked.

## Risks

Include any control this decision relies on that has not yet been shown to work. It stays a risk
until a run shows it working (U20).
