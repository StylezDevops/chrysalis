# Fix record: the defect, in one line

Copy for any fix that needs more than a register row. Link it from the row.

## Problem

What was wrong, measured (U1): the number before, and how a user or a gate would see it.

## Fix

What changed.

## What makes it correct

The details a reviewer could miss: ordering, the edge case handled, why the obvious simpler fix was
wrong.

## What it does not change

Behaviour, interfaces and data deliberately left as they were.

## Testing

| Check | Kind | Result |
|---|---|---|
| | regression test / real input / differential / human | |

What could not be tested, and why. Each item becomes an open item with an owner; "could not test" is
never left as a sentence.
